# hosp.jp への公開手順（公共施設複合化ポータル）

公開先は **https://hosp.jp/fukugo/** です。ほかのポータル（/fm/ や /kotsu/）と同じ並びに置きます。

## 1. ファイルをアップロードする

サーバーの、`fm` や `kotsu` のフォルダがあるのと同じ場所に `fukugo` フォルダを作り、次のファイルを入れます。

```
fukugo/
├── index.html      … トップ
├── paper.html      … 論点整理ペーパー
├── cases.html      … 事例集
├── glossary.html   … 用語集
└── assets/
    └── portal.css  … デザイン
```

`_build/` と、この `UPLOAD.md` はアップロードしません（ページを作り直すための道具と手順書です）。

## 2. GA4 の計測

4つのページすべての `<head>` に、全ポータル共通の測定ID **G-JPKJQ6S6Y9** のタグを入れてあります。追加の作業はいりません。

アップロード後、GA4 の「リアルタイム」を開いたまま https://hosp.jp/fukugo/ を表示し、閲覧が1件増えれば計測できています。

## 3. トップページのカード（テーマ別ポータル）

WordPress でトップページを編集し、「テーマ別ポータル」の **PUBLIC FACILITY PORTAL（公共施設の統廃合・再編）のカードを複製** して、すぐ後ろに置きます。複製したカードの文字とリンクを、次のとおり差し替えます。

| 項目 | 入れる内容 |
| --- | --- |
| 英字のラベル | FACILITY COMPLEX PORTAL |
| キャッチ（2行） | まとめるだけでは、／にぎわわない。 |
| 見出し | 公共施設と商業・文化・福祉をつなぐ複合化ポータル |
| 案内の文 | 公共施設の複合化ポータルへ → |
| リンク先 | https://hosp.jp/fukugo/ |

既存のカードを複製すると、デザインがほかのカードとそろいます。

## 4. 関連ポータルのナビ

このポータルのナビには、/fm/ と同じ並びで全ポータルへのリンクを入れ、「公共施設マネジメント」の次に「公共施設の複合化」を置きました。

ほかのポータルの側にも、関連ポータルの行の「公共施設マネジメント」の次に、次の1行を足します。

```html
<a href="https://hosp.jp/fukugo/">公共施設の複合化</a>
```

WordPress のメニュー（外観 → メニュー）にポータルの一覧がある場合は、そこにも「カスタムリンク」で同じリンクを足します。
