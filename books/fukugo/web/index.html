商業・文化・福祉・交通を「広場」でつなぐ——自治体とデベロッパーの実務

上村　章文

公共施設を「何と、どこで、どう束ねるか」を、自治体と商業施設のデベロッパーの双方が判断できるようにする本です。

全国の事例を組み合わせごとに整理し、人口規模別に「理想・次善・最低限」を示します。このページでは、目次と各章の要点を紹介しています。事例の詳しい経緯、数字、点検表は本に載せています。

序章　なぜ「減らす」から「組み替える」へなのか

この章の要点

  1. 公共施設等総合管理計画は、全団体がつくった。それでも施設の総量は、10年で1.3%増えた。
  2. 人口が減り、建物が古くなり、担い手が減る。三つの圧力は同時に来る。
  3. この数年で、複合化を支える制度が相次いで作り替えられた。最も有利な借入れの期限は、2026年度で切れる。
  4. 複合化は、面積を減らす手段ではない。地域に必要な機能を、人が集まり、運営しやすい形に組み替える手段である。
  5. 本書は、自治体と商業施設（デベロッパー、SCの運営会社）の両方に向けて書いた。同じ事例を、両側から読めるようにしてある。

第1章　外部経済効果を「広場」でつなぐ

この章の要点

  1. 商業施設にも公共施設にも、外部経済効果がある。使う人の外にまで、便益が広がる。
  2. 二つの効果は性格が違う。公共は平日の昼に、商業は週末と夕方に人を呼ぶ。だから組み合わせると強くなる。
  3. 自動車社会は、施設を道路と駐車場で切り離した。効果は互いに届かなくなった。
  4. 複合化は建物の中で完結させない。建物の前に広場を置き、入口を広場に向ける。
  5. 広場はつくるだけでは人が集まらない。運営する人と予算を、建物と同時に用意する。

第2章　何と何を組み合わせるか（4つの類型）

この章の要点

  1. 複合化は、組み合わせる相手で4つの類型に分けられる。公共×公共、公共×商業、公共×働く場、公共×住まい・医療福祉である。
  2. 相手が民間に近づくほど、にぎわいと民間資金を引き出せる。その分、商売が成り立たないときのリスクも大きくなる。
  3. 類型は、四つの問いで選ぶ。利用時間帯は補い合うか、利用者は重なるか、民間が稼げる立地か、その場所に残すべき機能か。
  4. 多くの自治体にとって、出発点は学校を核にした公共×公共である。
  5. 商業や働く場は、市場性を確かめてから小さな床で足す。最初から大きく建てない。

第4章　公共×公共——学校を核にする

この章の要点

  1. 学校は、市区町村が持つ施設の床の約4割を占め、通学区という地域の単位を持つ。複合化の核として、これ以上の候補はない。
  2. 学校の約39%は、すでにほかの施設と複合化している。しかし相手の多くは備蓄倉庫と放課後児童クラブで、図書館や公民館との本格的な複合はまだ少ない。
  3. 学校を核にするときの最大の論点は、安全管理である。入口と動線、管理の区分、設備の系統という「境目」を、設計の段階で決める。
  4. 国の補助で建てた学校を他の用途に使う手続（財産処分）は、思われているより軽い。壁になりやすいのは、制度より庁内の縦割りである。
  5. 逆向きの複合化もある。学校のプールを畳み、民間や拠点校の施設に授業を移すのも、学校を核にした組み替えである。

第5章　公共×商業——床を借りるか、持つか

この章の要点

  1. 商業施設に公共施設を入れるとき、自治体の選択は床を借りるか、床を持つかの二つに分かれる。費用の出方とリスクの持ち方が、まったく違う。
  2. 借りれば、早く始められ、動きやすい。その代わり、賃料が毎年かかり続ける。駅前の商業施設に図書館を移した藤沢市は、年に約1億円の賃料を払っている。
  3. 持てば、腰を据えられ、商業施設の存続も支えられる。その代わり、建物の将来を他の所有者と一緒に決めることになる。
  4. 選ぶ基準は五つある。いつまでいたいか、相手はいつまで続くか、総額はどちらが安いか、修繕と建て替えを誰が決めるか、財源は何か。
  5. どちらを選んでも、「商業施設が閉じたらどうするか」を、入る前に契約で決める。

第6章　文化×商業——入口に商業、奥に文化

この章の要点

  1. 図書館・美術館・ホールは、誰でも無料か安く来られ、長く過ごせる施設である。商業から見れば強い集客の装置であり、文化の側から見れば、商業は来館のきっかけと運営費の支えになる。
  2. ただし、文化施設を入れれば商業が救える、とは限らない。青森市のアウガは、図書館を入れても商業を救えなかった（第3章）。
  3. 融合には四つの型がある。文化の中に商業、商業の中に文化、公共が商業の形をとる、隣り合わせて回遊させる、である。
  4. 設計の基本は、入口に商業、奥に文化である。カフェや書店で気軽に入れるようにし、奥や上の階で静かに読み、学べるようにする。
  5. 選書や企画など、文化の中身は公共が責任を持つ。それを契約に書く。

第7章　公民館×カフェ・居酒屋

この章の要点

  1. 公民館は、昼の高齢者とサークルが中心で、夜の時間、働く世代、若い世代がほとんど来ない。カフェや居酒屋は、「用がなくても立ち寄れる」入口になる。
  2. 公民館は営利の事業を禁じられている、と思われがちである。しかし文部科学省は、営利の事業に関わることを全面的に禁じるものではないとしている（2018年12月の事務連絡）。問題は、特定の事業者だけを優遇することである。

  4. お酒を出すには、許可より先に使用の規則が壁になる。多くの公民館は飲酒を禁じている。
  5. 毎日の営業から始めない。週末の夜や月1回の営業で、利用者と近所の反応を確かめる。

第9章　公園×収益施設——Park-PFIの先へ

この章の要点

  1. 公園は、本来「建物をできるだけ建てない」公共空間である。複合化の対象として、最も慎重さが要る。
  2. Park-PFI（公園の飲食店などの収益で、公園の整備費を賄う制度）は、2026年3月末で203か所で使われている。ただし大都市圏に偏り、人が集まらない地域では成り立ちにくい。

第10章　食を核にする

この章の要点

  1. 食は、毎日の需要があり、誰でも関われ、滞在の時間を生むテーマである。市場、飲食、学び、研究を一つの拠点にまとめやすい。

第11章　地域公共交通×複合施設

この章の要点

  1. 施設をまとめると、必ず「遠くなる人」が出る。統廃合への反対の多くは、「通えなくなる」という不安である。

  5. 住民への説明は、「距離」ではなく「行きやすさ」で行う。乗り換えなしで行けるか、何分かかるか、1日何便あるかを示す。

第12章　商業の稼ぎで公共を支える（収益還元）

この章の要点

  1. Park-PFI の考え方は、経済の理屈にかなっている。市場で稼げる施設の利益で、料金では回収できないが、まわりに大きな便益を生む施設を支える。
  2. 仕組みは五つの部品に分けられる。稼ぐ施設、還元する先、民間への見返り、国の支援、選び方である。
  3. 同じ原理は、公園に限らない。水辺、道路、合築の建物、公共施設の中の床など、七つのパターンに広げられる。
  4. 制度の設計では、見返りと還元の釣り合いを出発点にする。見返りを小さくしたまま大きな還元を求めれば、応募がなくなる。
  5. 人口の少ない地域では、商業の稼ぎと公共の負担を組み合わせる「混合型」を、最初から認める。

第13章　お金をどう用意するか

この章の要点

  1. 財源は、「国の有利な借入れ・補助」と「民間の資金や土地の価値」の2本立てで考える。
  2. 複合化に最も有利な借入れは、公共施設等適正管理推進事業債（以下、適正管理債）である。事業費の90%を借りられ、返済額の50%を国が地方交付税で手当てする。その期限は2026年度で、2027年度以降の扱いは本書の執筆時点で公表されていない。
  3. 解体だけを単独で行うと、国の手当てはない。解体は、必ず複合化とセットで計画する。
  4. 民間の資金は、定期借地、床の貸付、余った容積の活用、PFI の四つの手法で引き出す。
  5. 企業版ふるさと納税は、集まれば充実させる上乗せの財源として扱う。確実な財源として当てにしない。寄附企業に見返りを与えないよう、公益の部分と営利の部分を分ける。

第14章　誰がどう運営するか

この章の要点

  1. 複合施設の成否は、建物全体の面倒を誰が見るかで決まる。担当課ごとに管理者が分かれたままだと、「同じ建物に別々の施設が入っているだけ」になる。
  2. 運営のモデルは四つある。担当課別、一体の指定管理、公共は指定管理・民間は賃貸、民間が建てて持ち行政が使う、である。
  3. どのモデルでも、点検・清掃・小さな修繕をまとめて民間に任せる包括管理を土台に置くと、技術職員が少ない自治体でも管理の質を保てる。
  4. リスクは、最もうまく管理できる側が持つ。日々の運営の工夫は民間、制度の変更は行政、人口減少による利用の減少は両者で分ける。
  5. 図書館や子育て支援のような公共性の高い機能に、独立採算を求めない。必要な運営費を払うことは、失敗ではなく前提である。

第15章　試してから決める（合意形成）

この章の要点

  1. 失敗の多くは、「決め方」ではなく「決める前の進め方」で起きている。
  2. 守るべきは順序・回数・等価性の三つである。削減の案を最初に出さない。対話の回数を予算に書き込む。移る先の機能が、いまと同じ役割を果たせるかを正直に説明する。
  3. 複合化には、複合化に特有の不安がある。利用者、保護者、地域の住民、地元の事業者、議会のそれぞれに、応え方を用意する。
  4. 図面と数字だけで判断を求めると、住民は失うものだけを見る。社会実験で実物を見せてから、本格化する。
  5. ただし、「結果がこうなら、こうする」という出口を先に決める。試行を、先送りの口実にしない。

第17章　公共テナントは商業施設に何をもたらすか

この章の要点

  1. 図書館、子育て支援、行政窓口などの公共施設は、商業施設から見れば平日の昼に人を呼ぶテナントである。
  2. 利点は4つある。集客、長く続く賃料、埋めにくい床の活用、施設の信用である。
  3. 一方で、民間テナントにはない制約がある。賃料の水準、単年度の予算、開館時間、公共の仕様、政策が変わったときの撤退である。
  4. 入り方は4つある。どれを選ぶかで、誰がどのリスクを負うかが決まる。
  5. 事業計画では、公共の賃料を固定の収入、集客の効果を上振れの要素として分けて見込む。

第18章　自治体の決め方と時間軸を読む

この章の要点

  1. 自治体は、公正公平な対応を常に求められる。だから、決めるたびに「理屈」が要る。担当者が庁内・議会・住民に説明できる理屈を持てない提案は、通らない。
  2. 自治体の決定は、計画の階段を一段ずつ上る。民間が意見を出せる局面は限られている。最も効くのは、事業化の検討段階のサウンディングである。
  3. 予算は1年のサイクルで動く。翌年度の予算の中身は、9〜10月までに固まる。2月の予算案の公表を見て動き始めるのは、1年遅い。
  4. 複数年の約束には、債務負担行為か長期継続契約が要る。PFI の契約や財産の取得には、議会の議決が要る。
  5. 構想から開業までは、短くても2〜3年、長ければ7年以上かかる。その間に首長の選挙をまたぐことを、計画に織り込む。

第19章　通る提案の組み立て

この章の要点

  1. 通る提案は、担当者がそのまま説明に使える理屈と、計画の階段のどこに乗るかの二つを備えている。自社の商品の説明から始めない。

第20章　ショッピングセンターの次の戦略——公共を取り込み、地域の拠点になる

この章の要点

  1. ショッピングセンター（SC）は、郊外・大規模・単独の建物という型で伸びてきた。人口減少とネット通販、SCどうしの競争で、その型が効きにくくなっている。
  2. SC業界の中から、SCを買い物の場から人が集い、交わる地域の拠点に変えようという提案が出ている。2016年の「ソーシャライジングセンター」と、2021年に生まれた未来SC研究所の活動である。

  5. 地域の拠点になるための実務は、本書の各章に分かれている。この章は、SCの関係者がどの章で何を確かめればよいかを示す入口である。
