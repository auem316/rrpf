序章　なぜ「減らす」から「組み替える」へなのか

# 確認すること 済
0-1 施設を減らす計画に、減らして何を得るのかが書かれているか
0-2 人口・建物・担い手の三つの圧力を、自団体の数字で示せるか
0-3 適正管理債の期限（2026年度までの工事着手）と、自団体の候補事業の時期を突き合わせたか
0-4 期限を理由に、住民との対話の順序を飛ばしていないか
0-5 複合化の検討に、企画・財政・都市計画の各課が加わっているか

第1章　外部経済効果を「広場」でつなぐ

# 確認すること 済
1-1 複合施設の前に、誰でも入れる屋外の空間（広場）があるか
1-2 公共施設と商業の入口が、広場に向いているか
1-3 駐車場が、広場と施設のあいだに挟まっていないか
1-4 広場から、ほかの施設や商店街へ歩いて行けるか
1-5 広場を運営する人（組織）が決まっているか
1-6 広場の運営費が、建物の事業費と同じ表に書かれているか
1-7 広場を使う規則（出店、飲食、音、時間）が決まっているか
1-8 建て替えの時期がずれる施設についても、将来置く場所が決まっているか

第2章　何と何を組み合わせるか（4つの類型）

# 確認すること 済
2-1 候補の施設が「残す・束ねる・転じる・畳む」のうち「束ねる」と判断されているか
2-2 組み合わせる施設の利用時間帯が、補い合っているか
2-3 利用者が重なり、「ついでに寄る」動きが見込めるか
2-4 商業や働く場を入れる場合、民間が稼げる立地かを確かめたか（サウンディング・暫定利用）
2-5 学校を核にする場合、学校の区域と地域の区域の境目を設計で決めているか
2-6 商業は、空いた床を貸すなど小さな形から始めているか
2-7 大都市の事例（豊島区など）を、条件の違いを確かめずに当てはめていないか

第3章　地方の再開発はなぜ失敗したか

# 確認すること 済
3-1 計画の出発点が、再開発ビルではなく公共施設の再編計画になっているか
3-2 集客の核が、毎日人が来る公共機能になっているか
3-3 商業の規模が、先に決まった（または意向を確かめた）テナントの賃料から逆算されているか
3-4 売上と賃料の見込みに、人口や商圏が伸びる前提を置いていないか
3-5 第三セクターが保留床を抱える形になっていないか。自治体が債務を保証していないか
3-6 公共施設を入れる場合、近くの古い施設を畳む計画がセットになっているか
3-7 床を持つ場合、建物の寿命までの修繕費の分担が見積もられているか
3-8 不振のときの見直しと撤退のルールが、契約に書かれているか
3-9 将来、商業を公共や住宅に変えられる設計になっているか

第4章　公共×公共——学校を核にする

# 確認すること 済
4-1 学校の一覧を、建て替え・統合の時期の順に並べ、複合化の候補の順番を決めたか
4-2 組み込む施設が、学校の空いている時間（放課後・夜・休日・長期休み）を埋めるか
4-3 場所・時間・管理・お金の四つの境目を、設計の前に決めたか
4-4 電気・ガス・水道の系統を、施設ごとに分ける設計になっているか
4-5 施設ごとの担当者による連絡協議の場を、開館の前に設けたか
4-6 国の補助で建てた校舎の財産処分の扱い（手続の要否・国庫納付）を確かめたか
4-7 教育委員会と首長部局（子育て・福祉）を、一つの検討の場に集めているか
4-8 統合の合意を先に取り、複合化の中身は統合の話し合いの中で聞いているか
4-9 将来、用途を入れ替えられる造りになっているか
4-10 プールなど、学校の機能を外の施設に移す選択肢も比べたか

第5章　公共×商業——床を借りるか、持つか

# 確認すること 済
5-1 その場所に何年いるつもりかを、先に決めたか
5-2 借りる場合と持つ場合の総額を、同じ期間で比べたか
5-3 商業施設が先に閉じた場合に、公共だけで床を使い切れるかを考えたか
5-4 持つ場合、管理規約での議決権、修繕積立金、建て替えの決め方を確かめたか
5-5 借りる場合、期間・中途解約・賃料改定・内装・原状回復を契約に書いたか
5-6 複数年の賃貸借を、債務負担行為と長期継続契約のどちらで扱うか、財政課と決めたか
5-7 商業施設が閉じるとき・建て替えるときの扱いを、入る前に契約に書いたか
5-8 入れる機能が、商業施設の弱い時間に人を呼ぶものになっているか
5-9 企業版ふるさと納税を使う場合、公益部分と営利部分のお金・所有・契約を分けたか

第6章　文化×商業——入口に商業、奥に文化

# 確認すること 済
6-1 文化施設を入れる前提として、商業が自分の足で立てる規模になっているか
6-2 四つの型（文化の中に商業／商業の中に文化／公共が商業の形／隣り合わせて回遊）のどれを取るかを決めたか
6-3 機能を「にぎやかなものから静かなものへ」の順に並べ、動線にしたか
6-4 選書の方針、郷土資料、企画のうち、公共が握るものを契約に書いたか
6-5 評価の物差しに、来館者数のほか、貸出・講座・地域資料の利用などを並べたか
6-6 商業の区画の広さと場所を、契約で固定したか
6-7 地域の書店や飲食店とのすみ分け（分野・時間・賃料）を考えたか

第7章　公民館×カフェ・居酒屋

# 確認すること 済
7-1 公民館の利用者の偏り（時間帯・世代）を、数字で確かめたか
7-2 社会教育法第23条の解釈（2013年3月の通知、2018年12月の事務連絡）を、庁内で共有したか
7-3 三つの道筋（公民館のまま貸す／コミセンに切り替える／住民の組織が運営）のどれを取るかを決めたか
7-4 事業者を公正に選び、賃料を相場に合わせているか
7-5 使用の規則の飲食・飲酒の扱いを確かめ、見直すか、区画を切り出すかを決めたか
7-6 飲食店営業の許可、持ち帰りの酒類販売、深夜の営業の届出の要否を確かめたか
7-7 週末の夜や月1回など、期間を区切った試行から始めているか
7-8 子どもの利用時間との区分、音、飲酒運転の防止を考えたか

第8章　福祉×商業・文化——幼老複合をまちの居場所に

# 確認すること 済
8-1 福祉と関係のない住民が、そこに来る理由（温泉・食堂・カフェ・売店・本など）を用意したか
8-2 三つの段階（福祉×福祉／福祉×商業／福祉×文化）のどこを目指すかを決めたか
8-3 共用部分が設備の基準の面積に数えられるかを、所管の部署と詰めたか
8-4 商業の部分と、子どもや高齢者の生活の場の動線を分け、交流の場だけを重ねたか
8-5 感染症がはやったときに閉じられる区切りを設計に入れたか
8-6 福祉の整備の補助と、商業の部分の面積・費用の按分を決めたか
8-7 公有地や床を出すとき、公募の条件と評価の項目に「地域に開く機能」を入れたか
8-8 民間が運営する福祉施設の場所と更新の時期を、公共施設の再編の地図に載せたか

第9章　公園×収益施設——Park-PFIの先へ

# 確認すること 済
9-1 その公園で、収益施設が成り立つだけの人の流れがあるかを確かめたか
9-2 収益施設が、公園の主役ではなく脇役の規模にとどまっているか
9-3 Park-PFI の前に、設置の許可や「活用のルール」で足りないかを考えたか
9-4 建物の面積の基準（条例）と、設置の期間を確かめたか
9-5 催しや物販の許可を、公園ごとのルールでまとめられないか検討したか
9-6 収益の還元を、固定の額にするか売上に連動させるかを決めたか
9-7 イベント広場の日常の利用と催しの利用の時間の配分を決めたか
9-8 総合運動公園の場合、強い核があるか。なければ既存の施設の再編から考えているか

第10章　食を核にする

# 確認すること 済
10-1 公設市場や産直の場所と、建て替え・再整備の時期を調べたか
10-2 五つの要素（市場・飲食・人材育成・研究開発・交流）のうち、何から始めるかを決めたか
10-3 建て替えの場合、上の階に何を重ねるか、仮設の期間をどう乗り切るかを考えたか
10-4 飲食・物販は民間の独立採算、人材育成・研究は公共や大学、と役割を分けたか
10-5 生鮮食品の店に残す床の割合を、公募や契約の条件に書いたか
10-6 評価の物差しに、地元の人の利用と地域の生産者の出荷を入れたか
10-7 常設の前に、マルシェやキッチンカーで需要を確かめたか

第11章　地域公共交通×複合施設

# 確認すること 済
11-1 複合化の候補地を、バスの路線・便数と同じ地図の上で検討したか
11-2 施設の担当課と交通の担当課を、同じ検討の場に集めたか
11-3 四つの型（結節型・拠点型・回遊型・共有型）のどれを取るかを決めたか
11-4 バスの待合を、施設のロビーに組み込んだか
11-5 開館・窓口・診療の時間と、バスのダイヤをそろえたか
11-6 福祉・教育・医療の送迎とコミュニティバスの予算を、一つの表にまとめたか
11-7 送迎の車を地域に開く場合、責任と保険の分け方を協定で決めたか
11-8 補助金が終わったあとの運行の財源を確かめたか
11-9 住民への説明で、乗り換え・所要時間・便数を示したか

第12章　商業の稼ぎで公共を支える（収益還元）

# 確認すること 済
12-1 「何の稼ぎで、何を支えるか」を一行で書けるか
12-2 七つのパターンのどれに当たるかを決めたか
12-3 還元の受け取り方（整備・地代・床・運営の肩代わり・売上の分配）を公募の前に決めたか
12-4 民間への見返り（期間・建てられる量・使い方の自由）を、還元と釣り合う大きさで示したか
12-5 市場性が足りない場合の混合型（市の負担との組み合わせ）を認めているか
12-6 無料で使える面積の割合や開放の時間など、公共性のルールを数字で契約に書いたか
12-7 不振・撤退・期間満了のときの建物の扱いを契約に入れたか
12-8 売上・還元の額・公共部分の利用を毎年公開する仕組みを決めたか

第13章　お金をどう用意するか

# 確認すること 済
13-1 稼ぐ部分（民間の資金）と稼がない部分（国の支援と地方債）を分けたか
13-2 適正管理債の対象になるか（個別施設計画への位置付け、延床面積・経費の削減）を確かめたか
13-3 2026年度の工事着手に間に合うか。間に合わない場合の財源を考えたか
13-4 畳む施設の解体の時期と費用を、複合化の計画に書き込んだか
13-5 学校・社会体育施設・都市機能誘導区域など、使える補助を先に当てたか
13-6 定期借地・床の貸付・余った容積・PFI のうち、どれを使うかを決めたか
13-7 PFI を選ぶ前に、費用の削減の効果（VFM）を確かめたか
13-8 企業版ふるさと納税を、上乗せの財源として扱っているか（額を約束していないか）
13-9 寄附企業が施設の事業者でもある場合、公益と営利のお金・所有・契約を分けたか
13-10 床と財源の対応表をつくったか

第17章　公共テナントは商業施設に何をもたらすか

# 確認すること 済
17-1 入居する公共施設が、自治体の施設再編計画（公共施設等総合管理計画・個別施設計画）に位置付けられているか
17-2 公共施設を移したあと、もとの施設を畳む計画になっているか
17-3 賃料（または売却価格）の根拠を、第三者の評価で示せるか
17-4 複数年の契約に必要な議会の議決の時期と見通しが分かっているか
17-5 開館時間と営業時間のずれに合わせて、入口・動線・警備の分担を決めているか
17-6 内装工事の範囲と費用の分担が決まっているか
17-7 中途解約の条件と原状回復の扱いが、契約に書かれているか
17-8 区分所有の場合、建物の寿命までの修繕費の分担が決まっているか
17-9 企業版ふるさと納税が絡む場合、寄附と床の取引が切り分けられているか
17-10 事業計画で、集客の効果を確実な収入に入れていないか
