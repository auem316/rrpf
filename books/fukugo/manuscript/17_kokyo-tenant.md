# 第17章　公共テナントは商業施設に何をもたらすか

## この章の要点

- 図書館や子育て支援、行政窓口などの公共施設は、商業施設にとって**平日の昼に人を呼ぶテナント**である。週末と夕方に偏りがちな人出を、平らにならす
- 公共テナントの利点は、集客、長く続く賃料、埋めにくい床の活用、施設の信用の4つにまとめられる
- 一方で、賃料の水準、単年度の予算、開館時間、公共の仕様、政策が変わったときの撤退など、**民間テナントにはない制約**がある
- 入り方は、①自治体が床を借りる、②床を買って区分所有する、③民間が建てて公共部分を自治体が買い取る、④公有地を定期借地で民間に貸す、の4つ。**どれを選ぶかで、誰がどのリスクを負うかが決まる**
- 事業計画では、公共の賃料を「固定の収入」、集客の効果を「上振れの要素」として分けて見込む

---

## 17-1　なぜ今、公共テナントなのか

人口が減り、ネット通販が広がるなかで、商業施設は「物を売る場所」だけでは人を呼びにくくなっています。とくに地方の大型店や駅前のビルでは、空いた区画や、物販では埋めにくい広い床が出ています。

自治体の側にも事情があります。古くなった公共施設を同じ場所に建て替える余裕がなく、施設をまとめて数を減らす計画を進めています（第2章）。建物を新しく建てずに、人の集まる場所に公共サービスを置けるなら、自治体にとっても利点があります。

両者の事情が重なるところに、**商業施設への公共テナントの入居**という選択肢があります。本章では、デベロッパーや商業施設の運営者の立場から、この選択肢を検討します。

## 17-2　公共テナントがもたらす4つの利点

| | 利点 | 中身 |
| --- | --- | --- |
| 1 | 集客 | 図書館、子育て支援、行政窓口、健診などは、生活の必要から人を呼ぶ。平日の昼にも人が来て、景気の影響を受けにくい |
| 2 | 長く続く賃料 | 自治体が撤退するのは、施設の再編など政策上の理由が中心で、売上の不振で撤退することはない |
| 3 | 埋めにくい床の活用 | 図書館や子育て広場は、広い床や上の階でも使える。物販のテナントが入りにくい区画を埋められる |
| 4 | 施設の信用 | 公共サービスがあることで、施設が「地域の拠点」として認められ、地域との関係も築きやすくなる |

**1つめの集客は、時間帯の補い合いに価値があります。** 商業施設の人出は、週末と夕方に波があります。公共施設は、平日の昼に安定して人を呼びます。子育て中の親が、子育て広場の帰りに食料品を買う。図書館に来た高齢者が、カフェで休む。互いの弱い時間帯を、相手が埋めます（第1章）。

ただし、公共施設の来館者が実際にどれだけ買い物をするかを示す公開データは、本書の執筆時点では見つけられていません【要確認】。**集客の効果は、事業計画では上振れの要素として扱う**のが安全です（17-6）。

## 17-3　公共テナントの制約

公共テナントには、民間テナントとは違う制約があります。参入の前に知っておくべき点を並べます。

| 制約 | 何が起きるか | 備え |
| --- | --- | --- |
| 賃料の水準 | 自治体は相場を超える賃料を払えない。逆に安すぎると「民間への優遇」と批判される | 不動産鑑定などで賃料の根拠を示せるようにする |
| 単年度の予算 | 自治体の予算は年度ごとに議会で決まる。複数年の賃貸借には、議会の議決（債務負担行為など）が要る | 契約の前に、議会の議決の時期と見通しを確かめる |
| 開館時間 | 公共施設の開館時間と休館日は条例などで決まり、商業施設の営業時間と合わないことがある | 入口や動線を分け、時間外の出入りと警備の分担を決める |
| 公共の仕様 | 図書館の床の重さ、バリアフリー、個人情報を扱う窓口の区画など、求められる仕様が商業より厳しいことがある | 内装工事の範囲と費用の分担を、募集の段階で確かめる |
| 政策が変わったときの撤退 | 首長の交代や施設の再編方針の見直しで、計画の凍結や撤退が起こりうる | 中途解約の条件と、原状回復の扱いを契約に書く |
| 公平性 | 特定の民間施設を選ぶ理由を、住民と議会に説明する必要がある | 公募や選定の経緯を記録し、立地を選んだ根拠を示す |
| 企業版ふるさと納税 | 寄附企業に経済的な見返りを与えることは禁止で、違反すると計画の認定取消の対象になる | 寄附する企業と床を貸す（売る）企業が同じなら、価格の根拠と選定の経緯を特に丁寧に示す（第13章） |

政策が変わったときの撤退は、デベロッパーにとって見落としやすいリスクです。愛知県西尾市では、約198億円・約30年の包括PFIの契約が市長交代後に凍結され、協議が長期化しました。公共テナントは売上の不振では撤退しませんが、**政策の変化では動きます。** その条件を契約で決めておきます。

## 17-4　4つの入り方

公共が商業施設とつながる入り方は、大きく4つあります。

| 入り方 | 仕組み | 民間の利点 | 民間の注意点 |
| --- | --- | --- | --- |
| ① 賃貸借 | 自治体が商業施設の区画を借り、公共サービスを置く | 床を持ったまま、賃料を得られる。始めるまでが早い | 賃料が毎年の予算に左右される。自治体が移転すると空く |
| ② 区分所有 | 自治体が商業施設の一部の床を買って持つ | 売却代金が一度に入る。公共が長く腰を据える | 修繕や建て替えに、自治体との合意が要る。商業部分が衰退しても自治体が抜け出しにくく、話し合いが重くなる |
| ③ 民間が建てて公共部分を買い取る | 民間が公共部分も含めて建て、完成後に自治体が公共部分を買い取る | 公共部分の売却代金で建設資金の一部をまかなえる | 自治体の予算の議決が遅れると、資金計画が狂う |
| ④ 定期借地 | 自治体が公有地を期限付きで民間に貸し、民間が商業施設を建てる | 土地を買わずに済み、初期投資が軽い | 期限が来たら更地にして返すのが原則。投資を期限内に回収する必要がある |

③と④は組み合わせて使えます。紫波町のオガールプラザがその例です（17-5）。

## 17-5　事例

### 紫波町 オガールプラザ（岩手県、2012年6月開業）――③と④の組み合わせ

民間の会社が、図書館・地域交流センター・子育て応援センターなどの公共部分と、産直・飲食・医療の民間部分を一体で建てました。工事費約11億円のうち、公共部分の約8億円を町が買い取り、民間部分の約2.7億円は民間が借入れでまかないました。民間部分の土地は32年の事業用定期借地で、地代は年348万円です。地代と税で、年約3千万円が町の収入になっています。

**テナントを先に決め、その賃料から建設費を逆算して資金を調達したとされます。** 公共部分が集客の核になり、民間部分は「稼げる規模しか建てない」設計です。

### ホルトホール大分（大分市、2013年7月開館）――公共と民間を事業方式で切り分ける

大分駅南に、市民ホール、市民図書館、社会福祉保健センター、保育所、子育て交流センターなどを集め、約1,500㎡の店舗・事務所も併設しました。延床面積は約36,500㎡です。

公共部分は民間が建てて運営し、市が対価を払います。**民間部分は独立採算です。** 募集のときには、民間部分を「別棟（土地を借りる）・合築・公共施設内のテナント」のどの形でも提案できるようにしていました（市の募集要項より）。公共と民間を「市が対価を払う部分」と「民間が自ら稼ぐ部分」に分けたことで、それぞれのリスクの持ち方がはっきりしています。

### 旧大宮図書館「Bibli」（さいたま市、2021年12月供用開始）――公共の建物に民間が入る

図書館の移転で空いた建物を、民間事業者が約2.5億円で改修し、飲食などのテナントに転貸しています。市には年約900万円の賃料が入る、約10年の賃貸借です。

公共テナントの「逆向き」の例です。民間から見ると、**自治体が手放した建物は、立地のよい床を改修費だけで手に入れる機会**になります。

### 秦野市（神奈川県）――小さな床と敷地から

保健福祉センターに郵便局を誘致し（年200万円の賃料）、庁舎の敷地には独立店舗型のコンビニを定期借地で置きました。大きな再開発でなくても、小さな床や敷地の貸し借りから公共と民間の組み合わせは始められます。

### 南アルプス市 南アルプスIC周辺整備事業（山梨県、2028年度開業予定）――公募で選ばれた商業施設に子育て・交流の場

市が進める同事業の中央エリアの活用の公募で、株式会社IDOMが選ばれ、2026年5月に市と立地協定を結びました。敷地約3.3haに、リユース商品の店舗と、屋内外のキッズエリア、絵本・児童書をそろえるブックミュージアム、地域の祭りやイベントに使う広場を備えた複合商業施設を計画しています（IDOM社の発表）。公共の関わり方の詳細は公表されていません。

### 反面の例：青森市 アウガ

商業と図書館などの公共施設が一つのビルに入った例ですが、商業の売上が計画の半分以下にとどまり、運営する第三セクターが事実上破綻しました（第3章）。**公共テナントがいても、商業の規模が需要を超えていれば、ビルは支えられません。** 公共テナントは集客の核になりますが、商業の見込み違いを埋め合わせるものではありません。

## 17-6　事業計画での見込み方

公共テナントを入れた事業計画では、収入を2つに分けて見込みます。

| | 見込み方 | 理由 |
| --- | --- | --- |
| 公共の賃料（または売却代金） | 固定の収入として見込む | 契約で額と期間が決まる。売上の不振では減らない |
| 公共施設による集客の効果 | 上振れの要素として見込み、確実な収入には入れない | 来館者の買い回りを示す公開データが乏しい【要確認】 |
| 政策変更による撤退 | 中途解約の条件を契約で決め、その場合の空き期間を感応度分析に入れる | 首長の交代や再編方針の見直しで起こりうる |

**集客の効果を確実な収入として織り込まない**ことが、アウガと逆の側に立つための条件です。開業後に、公共施設の来館者数と、同じ時間帯の商業の客数や売上を記録しておくと、次の案件の根拠になります。公表できる形で記録を残すことを、自治体と協定で決めておくのも一つの方法です。

## 17-7　規模に応じた3段の答え

デベロッパーの立場から、自治体の規模ごとに狙える形を整理します。

| | 理想 | 次善 | 最低限 |
| --- | --- | --- | --- |
| 人口20万人以上 | 駅前の再編で、公共部分を自治体が取得し、民間部分を独立採算で建てる（③または事業方式での切り分け） | 既存の商業施設に、図書館や子育て支援を賃貸借で入れる（①） | 移転で空く公共の建物を借りて改修し、テナントに転貸する |
| 人口5万〜20万人 | 公有地の定期借地と公共部分の買い取りを組み合わせ、テナントを先に決めて規模を逆算する（③＋④） | 商業施設の空き区画や上の階に、子育て広場や行政窓口を賃貸借で入れる（①） | 商業施設の一角に、出張窓口や相談会を期間を区切って置く |
| 人口5万人未満 | スーパーや道の駅に、支所・図書館の分室・子育て相談をまとめて入れる | 公共施設の空き床や敷地に、郵便局やコンビニを入れる（秦野市型） | 店の前や駐車場で、自治体と共催の市（いち）や催しを開く |

**小さな自治体ほど、商業施設は数少ない「人が集まる場所」**です。大きな開発でなくても、窓口や相談会を置くところから始められます。

## 17-8　点検表

公共テナントの入居を検討するときに、デベロッパーが確かめる項目です。

- [ ] 入居する公共施設が、自治体の施設再編計画（公共施設等総合管理計画・個別施設計画）に位置付けられている
- [ ] 公共施設を移したあと、もとの施設を畳む計画になっている
- [ ] 賃料（または売却価格）の根拠を、第三者の評価で示せる
- [ ] 複数年の契約に必要な議会の議決の時期と見通しが分かっている
- [ ] 開館時間と営業時間のずれに合わせて、入口・動線・警備の分担を決めている
- [ ] 内装工事の範囲と費用の分担が決まっている
- [ ] 中途解約の条件と原状回復の扱いが、契約に書かれている
- [ ] 区分所有の場合、建物の寿命までの修繕費の分担が決まっている
- [ ] 企業版ふるさと納税が絡む場合、寄附と床の取引が切り分けられている
- [ ] 事業計画で、集客の効果を確実な収入に入れていない

### 自治体から見ると

この章は、デベロッパーに向けて書いています。自治体の担当者が読むときは、裏返して読んでください。

**民間は何を気にしているか。**　①賃料と期間が契約でどこまで確かになるか、②政策が変わったときに何が起きるか、③開館時間や仕様の制約がどこまで重いか、の3つです。これらを募集の段階で示せる自治体ほど、提案が集まります。

**どこで失敗するか。**　商業施設に入ること自体を目的にすると、その場所に置く理由が薄くなり、第3章の「穴埋め」と同じ形になります。入居は、施設を畳んで移すための手段として計画に位置付けます。

**何を先に決めるか。**　①移す施設と畳む施設、②借りるか買うか、③予算の見通しと議会への諮り方、④撤退のときのルール、の4点です。
