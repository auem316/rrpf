# 第3章　地方の再開発はなぜ失敗したか

## この章の要点

- 地方の駅前や中心市街地では、再開発で建てた商業ビルにテナントが集まらず、**空いた床を自治体が公共施設で埋める**という結末が繰り返されてきた
- 失敗は個別の努力不足ではなく、**構造から起きている**。売上の楽観、保留床に頼るお金の仕組み、大型店への依存、郊外化の軽視、補助金による規模の膨張、公共の穴埋め、の6つの型がある
- 根っこにあるのは「**商業が主役、公共は脇役（または救済役）**」という順序である
- 複合化は、この順序を逆にする。公共施設の再編計画から始め、毎日人が来る公共機能を核に、商業は先に決まったテナントの分だけ足す
- 既存の空きビルに公共施設を入れるときは、**近くの古い施設を同時に畳み**、施設の総量を増やさない

---

## 3-1　再開発のお金の仕組み

まず、市街地再開発事業の仕組みを簡単に押さえます。

市街地再開発事業は、古い建物が建て込んだ区域で、土地と建物をまとめて取り壊し、大きなビルに建て替える事業です。もとの地権者は、持っていた土地や建物の価値に見合った床を新しいビルの中に受け取ります。これを**権利変換**といいます。

新しいビルは、もとの建物より大きく建てます。地権者に渡した分を超えて増えた床を**保留床**といいます。事業費の大きな部分は、この保留床を売ったり貸したりした代金と、国や自治体の補助金でまかないます。

| | 中身 | 地方で起きやすいこと |
| --- | --- | --- |
| 権利床 | もとの地権者が受け取る床 | 地権者が商売をやめ、床が空いたままになる |
| 保留床 | 増えた床。売ったり貸したりして事業費にあてる | 買い手や借り手がいない |
| 補助金 | 国・自治体が事業費の一部を負担する | 負担が軽く見え、規模が膨らむ |

都市の中心で床の需要が強いときは、この仕組みはよく回ります。保留床が高く売れ、その代金で道路や広場も整います。問題は、**地方では保留床の買い手がいない**ことです。誰も買わない床は、第三セクター（自治体が出資する会社）や自治体自身が引き受けることになります。ここから失敗の連鎖が始まります。

## 3-2　代表的な失敗例

### 青森市 アウガ（2001年開業）

事業費185億円の複合ビルです。地下に市場、1〜4階に商業、4〜9階に図書館などの公共施設が入りました。

初年度の売上は、計画の52億円に対して約23億円と、半分以下でした。運営する第三セクターは2015年度末に約24億円の債務超過となります。市は2008年に銀行の債権約23億円を買い取るなど支援を重ねましたが、2016年に市長が引責辞任しました。2017年2月に商業テナントが一斉に撤退し、2018年1月からは市役所の駅前庁舎として使われています。

### 秋田市 エリアなかいち（2012年開業）

事業費135億円で、その8割を国・県・市が負担しました。商業施設、県立美術館、市のにぎわい交流館で構成されています。開業から10年たっても商業の苦境は好転していないと報じられています。

### 全国の再開発ビル

大阪府がまとめた再開発ビルの空き床対策の事例集には、商業床の空きに公共施設を入れた例が13件挙げられています。北見市（市の分庁舎）、中津川市（市役所機能・多目的ホール）、岡谷市（生涯学習センター・子育て支援館）、久留米市（図書館など）、佐賀市（子育て支援センター・市民センター）、倉敷市（男女共同参画センター）などです。

**一つひとつの事例には、それぞれの事情があります。** ただ、13件も並ぶと、個別の事情では説明しきれない共通の流れが見えてきます。商業ビルを建て、商業が埋まらず、公共施設で埋める、という流れです。

## 3-3　失敗に共通する6つの型

| | 型 | 何が起きるか |
| --- | --- | --- |
| 1 | 売上の見込みが楽観的すぎる | 人口や商圏が伸びることを前提に計画し、売上や賃料が計画の半分程度で止まる（アウガは初年度で計画の半分以下） |
| 2 | お金の仕組みが保留床に頼っている | 地方では保留床の買い手がおらず、第三セクターや自治体が引き受ける |
| 3 | 核となる大型店（キーテナント）に頼っている | 百貨店やスーパーが撤退すると、ビル全体が一気に空く |
| 4 | 郊外化と車社会の現実を見ていない | 郊外のバイパス沿いに店が集まり、中心部は人通りも土地の値段も下がり続ける（青森では路線価が開業時の約3分の1に） |
| 5 | 補助金があるので規模が膨らむ | 事業費の多くを公費でまかなえるため、身の丈を超えた床を建てる |
| 6 | 公共施設があとから「穴埋め」で入る | その場所に置く必然性が薄いまま、床の管理費と修繕の積立てを自治体が払い続ける |

6つめの型は、本書のテーマである複合化と直接つながります。**空き床に公共施設を入れると、見た目は「複合施設」になります。** しかし、これは複合化ではありません。近くの古い施設を畳まずに入れれば、施設の総量はむしろ増えます。公共施設の総量を減らそうとする計画（公共施設等総合管理計画）と逆の方向に進んでしまいます。

6つの型の根っこにあるのは、**「商業が主役、公共は脇役（または救済役）」という順序**です。商業の需要が細る地方では、この順序そのものが成り立ちません。

## 3-4　順序を逆にする

複合化の考え方は、この順序を逆にすることです。公共を核に置き、商業はその人の流れに乗る規模で足します。

| | 失敗の型（商業先行・公共は穴埋め） | 融合の型（公共を核に商業を足す） |
| --- | --- | --- |
| 出発点 | 再開発ビルを建てること | 公共施設の再編計画（どの機能を中心部に集めるか） |
| 集客の核 | 百貨店・大型店 | 図書館・子育て・行政窓口・医療など毎日使う公共機能 |
| 商業の規模 | 計画上の需要から決める | 先に決めたテナントの賃料から逆算する |
| 床の持ち方 | 第三セクターが保留床を抱える | 公共部分は自治体が取得、民間部分は民間がリスクを負う |
| 地権者 | 床を受け取って終わり | 業績に連動する地代で一緒にリスクを負う |
| 公共施設 | 空き床に後から入る | 別の施設を畳んで移す（総量を増やさない） |
| 失敗したとき | 自治体が債務を肩代わり | 契約で決めた見直し・撤退のルールに従う |

第1章で見たとおり、公共施設は平日の昼にも安定して人を呼び、景気の影響を受けにくい集客の装置です。地方の中心部で、百貨店に代わって毎日人を呼べるのは、むしろ公共施設のほうです。**集客の核を、商業から公共に置き換える。** これが順序を逆にするということです。

## 3-5　順序を逆にした成功例

### 高松市 丸亀町商店街

地権者の土地を、まちづくり会社が定期借地でまとめて借ります。土地を持つことと使うことを分けて、店の構成を会社が一体で組み立てています。

地権者に払う地代は、会社の業績に連動して毎年見直します。売上が落ちれば地代も下がります。**地権者が「床を受け取って終わり」ではなく、運営会社と一緒にリスクを分け合う**仕組みです。

### 紫波町 オガールプラザ（岩手県、2012年6月開業）

図書館などの公共部分を核にして、テナントを先に決めました。建設費はテナントの賃料から逆算しています。工事費約11億円のうち、公共部分の約8億円を町が買い取り、民間部分の約2.7億円は民間が借入れで建てました。民間部分の土地は32年の事業用定期借地です。

「稼げる規模しか建てない」という考え方は、6つの型の1・2・5を、計画の最初の段階で断ち切っています。詳しくは第5章と第12章で扱います。

二つの例に共通するのは、**建物より先に、中身（運営する人と入居者）を決めている**ことです。

## 3-6　融合のための7つの原則

1. **施設再編計画から始める。**　再開発の計画ではなく、公共施設等総合管理計画のなかで「中心部に集める機能」と「畳む施設」を先に決めます。
2. **公共機能を集客の核にする。**　図書館、子育て支援、行政窓口、健診・医療など、毎日人が来る機能を核に据えます。商業はその人の流れに乗る規模にとどめます。
3. **テナントを先に決めて規模を逆算する。**　サウンディング（民間への事前の意向調査）や仮設の出店で需要を確かめます。そのうえで、入る店が決まった分だけ建てます。
4. **リスクを負う人を分ける。**　公共部分は自治体が持ち、商業部分は民間が借入れとリスクを負います。第三セクターに床を抱えさせたり、自治体が債務を保証したりはしません。
5. **土地は売らずに貸す。**　定期借地や、業績に連動する地代を使って、地権者と運営会社が同じ方向を向く仕組みにします。
6. **用途を変えられる建物にする。**　将来、商業が縮んでも公共や住宅に変えられるよう、柱と床だけの骨組みを長く使い、内装を入れ替えられる設計（スケルトン・インフィル）にします。
7. **既存の空きビルは「再編の受け皿」として使う。**　すでにある再開発ビルの空き床に公共施設を入れるときは、近くの古い施設を同時に畳み、施設の総量を増やさないことを条件にします。

## 3-7　すでにある空きビルをどうするか

多くの自治体にとって、目の前の課題は新しい再開発ではなく、**すでに建っている再開発ビルの空き床**です。ここに公共施設を入れること自体は、悪い選択ではありません。中心部に人を呼び戻す手段になります。違いを分けるのは、入れ方です。

| 確かめること | 穴埋めになる入れ方 | 再編の受け皿になる入れ方 |
| --- | --- | --- |
| 移す施設 | 新しい施設を足す | 近くの古い施設を畳んで移す |
| 施設の総量 | 増える | 増えない（減る） |
| 床の持ち方 | 自治体が床を買い取り、抱え続ける | 借りる期間を区切るか、買う場合は将来の修繕費まで見積もる |
| 修繕・建替えの分担 | 決めていない | 区分所有者との分担を先に決める |
| 置く理由 | 床が空いているから | 中心部に集める機能として計画に位置付けている |

再開発ビルは区分所有者が多く、大規模な修繕や建て替えの合意が難しくなりがちです。自治体が床を持つなら、**建物の寿命までの修繕費の分担を、買う前に見積もります。** 床の代金だけを見て判断すると、あとから重い負担が残ります。

## 3-8　規模に応じた3段の答え

| | 理想 | 次善 | 最低限 |
| --- | --- | --- | --- |
| 人口20万人以上 | 施設再編計画で中心部に集める機能を決め、公共を核にした再開発・建て替えを、テナントを先に決めてから進める | 既存の再開発ビルの空き床に、近くの古い施設を畳んで移す | 計画中の再開発について、売上と賃料の見込みを第三者に点検させる |
| 人口5万〜20万人 | 新しいビルは建てず、既存ビルの再生と小規模な連鎖型の建て替えで公共と商業を組み合わせる | 空き床を期間を区切って借り、公共機能を試しに置いてから買うかどうかを決める | 中心部の空きビルの床の持ち主・修繕積立・空き状況を一覧にする |
| 人口5万人未満 | 大きな再開発はせず、既存の建物の改修（リノベーション）で公共と小さな店を一体にする | 空き店舗の一区画に、窓口や子育て相談を出張で置く | 過去の再開発・中心市街地の事業について、計画と実績を比べて公開する |

**「最低限」の欄は、次の失敗を防ぐための準備**です。とくに計画と実績の比較は、どの規模の自治体でも始められます。公開すれば、次の計画で同じ見込み違いを繰り返さずに済みます。

## 3-9　点検表

再開発や空きビルの活用を含む複合化の計画が、失敗の型にはまっていないかを確かめます。

- [ ] 計画の出発点が、再開発ビルではなく公共施設の再編計画になっている
- [ ] 集客の核が、毎日人が来る公共機能になっている
- [ ] 商業の規模が、先に決まった（または意向を確かめた）テナントの賃料から逆算されている
- [ ] 売上と賃料の見込みに、人口や商圏が伸びる前提を置いていない
- [ ] 第三セクターが保留床を抱える形になっていない。自治体が債務を保証していない
- [ ] 公共施設を入れる場合、近くの古い施設を畳む計画がセットになっている
- [ ] 床を持つ場合、建物の寿命までの修繕費の分担が見積もられている
- [ ] 不振のときの見直しと撤退のルールが、契約に書かれている
- [ ] 将来、商業を公共や住宅に変えられる設計になっている

### デベロッパーから見ると

**稼げるか。**　地方の再開発で商業床を大きく持つ計画は、本章の6つの型のどれかに当たりやすく、事業として危うい計画です。逆に、公共部分を自治体が取得し、民間部分を先に決めたテナントの分だけ建てる計画なら、民間が負うリスクは小さく区切られます。**公共が核になる計画のほうが、民間にとっても読みやすい計画です。**

**どこにリスクがあるか。**　①自治体の財政事情や首長の交代で、公共部分の取得が遅れる・縮む。②地権者が多く、権利の調整に時間がかかる。③既存ビルでは、区分所有者のあいだで修繕や建て替えの合意がとれない。①には議会の議決（債務負担行為など）の時期を、②③には合意の見通しを、参入の前に確かめます。

**自治体に何を確かめるか。**　①公共施設等総合管理計画や個別施設計画で、その場所に集める機能が決まっているか、②畳む施設がどれか、③公共部分を取得するか借りるか、その予算の見通し、④不振や撤退のときのルールを契約に書く用意があるか、の4点です。
