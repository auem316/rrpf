# 第20章　ショッピングセンターの次の戦略——公共を取り込み、地域の拠点になる

## この章の要点

1. ショッピングセンター（SC）は、**郊外・大規模・単独の建物**という型で伸びてきた。人口減少とネット通販、SCどうしの競争で、その型が効きにくくなっている。
2. SC業界の中から、SCを買い物の場から**人が集い、交わる地域の拠点**に変えようという提案が出ている。2016年の「ソーシャライジングセンター」と、2021年に生まれた未来SC研究所の活動である。
3. 提案の柱は、**行政サービス、図書館、医療・福祉、子育ての機能を核テナントとして取り込み、行政や住民と一緒に運営する**ことである。これは、本書の「公共×商業」を商業の側から見たものにあたる。
4. ただし、**公共は集客の核であって、売上の見込み違いの穴埋めではない。**入れ方を誤れば、第3章の失敗をくり返す。
5. 地域の拠点になるための実務は、本書の各章に分かれている。**この章は、SCの関係者がどの章で何を確かめればよいかを示す入口である。**

---

## 20-1　SCの「勝ち方」が変わる

日本のSCは、車で来る客を前提に、郊外の広い土地に大きな建物を建てて伸びてきた。品ぞろえの多さと駐車場の広さが、そのまま強みになった。

その前提が揺らいでいる。商業施設が「物を売る場所」だけでは人を呼びにくくなった事情は、第17章17-1で見た。さらにSCどうしの競争が重なり、地方では空いた区画を埋められない施設が出ている。SCを支えてきたのは、高い歩合賃料を払えるアパレルだった。そのアパレルが売れなくなったことが、SCの衰えに拍車をかけているという指摘もある（20-2の対談）。

SC業界の中では、成功の条件そのものが変わるという見方が出ている。2016年の論文「ソーシャライジングセンター」は、SCの成功の条件が**「郊外」「大規模」「低層単独」から、「駅前／中心地」「コンパクト」「複合」へ移る**と書いた。

海外では、SCの空き床に医療や公共が入る動きが進んでいる。イギリスでは、国の検査体制の見直し（2020年）が、検査の拠点を商店街や郊外の商業施設の空き床に置くよう提言し、SCの中にCTやMRIを備えた検査センターが開いている。アメリカでは、空いたモールの上の階を大学病院のクリニックに改装した例がある（ナッシュビルの100 Oaks Mall、2009年）。図書館・保健センター・行政の窓口と地下鉄・バスの拠点まで一つにしたSCが、フィンランドのイソ・オメナである（第11章11-2）。

これは、本書の第1章の考え方と同じ向きである。SCの原型を考えたビクター・グルーエンは、歩いて暮らせるまちや、住む・働く・買う機能を混ぜたまちづくりを早くから唱え、「ショッピングモールの父」と呼ばれることを好まなかったとされる。**SCは、もともと「まちの広場」をつくる試みでもあった。**

## 20-2　SC業界から出ている提案

### ソーシャライジングセンター（2016年）

日本ショッピングセンター協会の「SC経営士誕生25周年記念論文」で、最優秀賞を受けた論文である。佐々木健雄氏、白川富章氏、ハーレイ・岡本氏が書いた。

2040年の都市の暮らしを想定し、SCを、**買い物だけでなく、自己実現と社交を促す場**に変えることを提案している。論文が挙げる条件は、次のとおりである。

| 条件 | 中身 |
| --- | --- |
| 立地と動線 | 駅に立地し、歩く人と車を分け、交通弱者を主体にした動線にする |
| 共用部 | 共用部の面積を、営業面積の半分以上にする。テナントの店内や共用部に、人が交わる仕掛けを置く |
| 建物 | 景観に合い、用途を変えられ、長く使える建物にする。緑化や自然エネルギーを使う |
| 運営 | デベロッパー、テナント、行政、住民で協議会をつくり、一緒に活動する |
| 会員 | 地域の住民が会員になり、施設を支える活動に応じた「会員通貨」が回る |

取り込む機能として、社会教育会館の機能を行政の委託で移すこと、クリニックや行政サービスを上の階に置くこと、託児所、図書館・美術館・劇場などを組み合わせた学びの場が挙げられている。行政との関係では、公有地の提供、建設費の補助、低い金利の融資、税の優遇、規制緩和の特区を、デベロッパーの負担を軽くする手段としている。

収支の試算もある。テナントの売上と賃料収入が減っても、入場料（年間の来館者500万人の1割が100円）と年会費（地域の住民5万人が1,000円）でそれぞれ年5千万円を得て、建物の償却期間の延長や管理費の削減と合わせれば、営業利益を保てるとする。

> **論文の芯は、SCの稼ぎ方を「売場の賃料」だけから、「地域の人の参加」にも広げることにある。**公共の機能は、その参加を呼ぶ入口として置かれている。

### 未来SC研究所と「縮充」（2021年〜）

ハーレイ・岡本氏、佐々木健雄氏、山田宗司氏の3人が共同で主宰する研究所である。2021年4月に設けられた。官民連携や地域連携を通じて、**地域のSCが生き残る道と、これからの姿を提案する**ことを掲げている。業界の有志約30人が月に1回、事例を研究し、2021年6月に『突破するSCビジネス　続／新ショッピングセンター論』（繊研新聞社）を出した。同書は、SCを、買い物から行政サービスの支援までを担う基盤の施設にすることを提案している。

山田氏と岡本氏は、2023年4月の対談（ジェイアール東日本企画「未来の商業施設ラボ」VOL.29・30）で、その考えを具体的に語っている。要点は次のとおりである。

| 論点 | 対談での主張 |
| --- | --- |
| 出発点 | 地方では、SCの空き床と、公共施設の床の持て余しが同時に起きている。行政の機能を別棟に分けてきた結果、住民は一か所で用を足せず、建物ごとに維持費と修繕費がかかる。**この二つを同時に解決する** |
| 縮充 | 縮めながら、中身を充実させる。機能を効率よく集めたコンパクトシティの、SC版をつくる |
| 組み方 | 公共施設をSCの**核テナント**にし、その機能と相性のよい商品やサービスの店を周りに置く。公共からは高い賃料を取れないので、SCが**指定管理者として管理料を得る**ことと、公共施設を使った**自主事業**で補う。SCと公共で二重にかかっていた床、人件費、催しをまとめる |
| 合う機能 | 子育て支援、健康づくり、図書館。地域の人が棚を借りて本を並べる、参加型の図書館を例に挙げている |
| 地域の知恵 | 「地域知財ミュージアム」をつくる。地域の人の知恵や特技、家庭の料理やレシピを発信し、次の世代に残す場である。優れたレシピを商品にすれば、SCの自主事業になる |
| 会費 | ミュージアムの利用者から会費を得る。使い道（たとえば子ども食堂の維持費）を公開し、地域に貢献している実感につなげる |

山田氏は、地方自治体の肩代わりができるのは地域に根ざしたSCであり、SCは地域を支える「公器」になるべきだと述べている。

山田氏が座長を務める日本ショッピングセンター協会近畿支部のSC研究推進委員会は、2023年度の研究のテーマを「地域連携・官民連携」とした。SC業界の中で、**行政と組むことが、生き残りの戦略として語られ始めている。**

## 20-4　SCの経営課題から、入れる公共を選ぶ

公共の機能は、何でも入れればよいわけではない。**SCが抱える課題と、公共の側の計画の両方に合うものを選ぶ。**

| SCの課題 | 合いやすい公共の機能 | 先に確かめること |
| --- | --- | --- |
| 平日の昼に人が少ない | 行政の窓口、図書館、子育て支援 | 自治体が、どの施設を畳んで移す計画を持っているか（第17章） |
| 大きな区画や上の階が空いている | 図書館、学びの場、子育て広場 | 公共の仕様（床の荷重、開館時間、出入口）に合うか（第5章） |
| 高齢の客が来にくくなった | 交通の結節点、出張の窓口、診療所 | SCがすでに交通の拠点になっているか。路線やデマンド交通を、自治体と一緒に組み替えられるか（第11章11-2） |
| 地域での存在感が薄い | 住民の活動の場、地域の催し | 住民と一緒に試す場を持てるか（第15章） |
| 次の世代の客が育たない | 子育て、学校との連携、学びの場 | 教育委員会や福祉の部署と話す窓口があるか（第4章、第8章） |

## 20-5　落とし穴——公共を救命具にしない

SCの関係者が公共との連携を考えるときに、とくに注意したいことは五つある。

1. **売上の不足を、公共で埋めようとしない。**公共の賃料は安定するが、売上の見込み違いを埋めるものではない。青森市のアウガは、その形で行き詰まった（第3章3-2）。
2. **公共テナントは、政策で動く。**売上の不振では出ていかないが、首長の交代や再編方針の見直しで動く。撤退の条件を契約に書く（第14章14-7、第17章17-3）。
3. **寄附と取引を混ぜない。**企業版ふるさと納税で寄附し、同じ施設で床を貸す・売る場合は、見返りの禁止に触れないよう、書類と経路を分ける（第13章13-4）。
4. **会員制や入場料と、公共サービスを分ける。**行政の窓口や図書館は、会員でなくても、お金を払わなくても使える場所でなければならない。会員の特典や入場料は、公共の部分とは別の部分にかける。
5. **指定管理料を、賃料の代わりとして固く見込まない。**指定管理者は、自治体が条例で定めた手続きで選び、議会の議決を経て指定する。期間が決まっていて、終われば改めて選ばれる必要がある。床を貸しているSCが、運営者に選ばれるとは限らない。選ばれなかった場合の収支も、あわせて組む（第14章14-2、第19章）。

> **地域の拠点になるとは、公共を利用することではなく、公共と一緒に場を運営することである。**

## 20-6　規模別の現実解——理想・次善・最低限

SCの立地する自治体の規模ごとに、狙える形を整理する。

| | 理想 | 次善 | 最低限 |
| --- | --- | --- | --- |
| 人口20万人以上 | 駅前・中心部のSCが、図書館や行政窓口を核に迎え、行政・テナント・住民の協議会で共用部を運営する | 空いた大区画に、図書館の分館や子育て広場を賃貸借で入れる | 共用部で、自治体と共催の講座や相談会を定期的に開く |
| 人口5万〜20万人 | 中心部のSCの再生を、自治体の施設の再編計画と同じ年度表に載せる | 上の階に行政窓口と子育て支援をまとめて入れ、バスの乗り場を施設の前に寄せる | 出張窓口や健診を、期間を区切って置く |
| 人口5万人未満 | スーパー核のSCや道の駅に、支所・図書館の分室・診療所をまとめる | 空いた区画を、住民の活動や交流の場として自治体と一緒に運営する | 健診や予防接種、選挙の期日前投票などを、店内で期間を区切って行う |

> **規模が小さいほど、建物を変える前に、運営の仕方を変えることから始められる。**協議会と催しは、投資がほとんど要らない。

## 20-7　自治体から見ると

**SCの関係者は、何を求めているか。**空いた床を長く埋める相手と、地域での信用である。売上の穴埋めを求めている相手かどうかは、収支の見込み方で分かる（第17章17-6）。

**どこを見るか。**協議会や住民の参加を、建物の話より先に持ち出すSCは、長く付き合える相手である。

**何に気をつけるか。**一つのSCとの話を、そのまま公募の条件にしないことである。民間からの提案は、公式の窓口で受け、公平に扱う（第18章）。

## 20-8　この章で覚えておくこと

SCが地域の拠点になる道は、**公共を取り込むことではなく、公共と一緒に場を運営すること**である。

そのために、最初に自治体に聞くことは一つである。**「この町は、どの施設を、いつ、どこへ移すつもりか」。**その答えの中に、SCの次の戦略がある。
