# 第1章　外部経済効果を「広場」でつなぐ

## この章の要点

- 商業施設にも公共施設にも、使う人の外にまで便益が広がる**外部経済効果**がある。複合化の価値は、この2つの効果を同じ場所で重ねることにある
- 自動車社会は、施設を道路と駐車場で切り離した。効果は互いに届かなくなり、歩いて回る人を失った中心部の商店街から衰退が進んだ
- ヨーロッパの町では、市庁舎・教会・市場が一つの広場を囲んできた。**行政と商いが同じ場所に集まること自体が、まちの価値になっている**
- 複合化は建物の中で完結させない。建物の前に広場を置き、入口を広場に向け、駐車場は外周にまとめる
- **広場はつくるだけでは人が集まらない。** 運営する人と予算を、建物と同時に用意する

---

## 1-1　外部経済効果とは何か

施設を使う人だけでなく、まわりの人や店にも便益が広がる効果を、**外部経済効果**といいます。

身近な例で考えます。商店街に店が集まっていると、客は一軒で用を済ませず、歩いて何軒も回ります。ある店を目当てに来た客が、隣の店でも買い物をします。店が集まること自体が、それぞれの店の売上を押し上げます。これが商業の外部経済効果です。

公共施設にも同じ力があります。役所の窓口、図書館、病院、子育て支援センターは、毎日、決まって人を呼びます。その人たちが帰りに買い物をし、お茶を飲みます。公共施設は料金ではほとんど稼ぎませんが、まわりの店にとっては、**毎日人を連れてきてくれる装置**です。

二つの効果には、性格の違いがあります。

| | 商業施設の外部経済効果 | 公共施設の外部経済効果 |
| --- | --- | --- |
| 人を呼ぶ理由 | 品ぞろえ、楽しさ、値段 | 手続、学び、子育て、医療など生活の必要 |
| 人の来かた | 週末や夕方に波がある | 平日の昼にも安定して来る |
| 景気の影響 | 受けやすい | 受けにくい |
| 本人の稼ぎ | 売上として回収する | 料金ではほとんど回収しない |

**この違いがあるから、組み合わせると強くなります。** 公共施設は平日の昼に安定して人を呼び、商業施設は週末と夕方ににぎわいをつくります。互いの弱い時間帯を、相手が埋めます。複合化の価値は、面積が減ることより、この二つの効果を同じ場所で重ねられることにあります。

## 1-2　自動車社会が分断したもの

車で移動する社会では、施設ごとに駐車場を持ち、人は目的地だけに行って帰ります。役所は郊外の広い敷地に移り、商業は幹線道路沿いの大型店に集まり、病院やホールはまた別の場所に建ちました。

施設どうしが道路と駐車場で切り離されると、それぞれの外部経済効果は互いに届きません。役所に来た人は、用事を済ませると車でまっすぐ帰ります。帰りに寄るはずだった店は、遠すぎて寄れません。歩いて回る人がいなくなった中心部の商店街から、衰退が進みました。

青森市では、郊外のバイパス沿いに店が集まり、中心部の路線価は再開発ビルの開業時の約3分の1まで下がったと報じられています（第3章）。

| | 自動車社会の配置 | 広場を中心にした配置 |
| --- | --- | --- |
| 施設の場所 | 役所・病院・大型店がばらばらの場所にある | 役所・文化施設・商業が広場を囲む |
| 人の動き | 車で目的地だけに行って帰る | 歩いていくつもの施設を回る |
| 外部経済効果 | 施設ごとに閉じ、まわりに届かない | 広場で重なり、互いを高め合う |
| 公共の空間 | 道路と駐車場 | 広場と歩行者の空間 |
| 商店街 | 衰退する | 回遊する人の受け皿になる |

ここで大事なのは、**施設の一つひとつは悪くない**ということです。郊外の役所も、大型店も、それぞれの理屈で正しい場所を選びました。問題は、全体として効果を打ち消し合う配置になったことです。施設を一つずつ建て替える限り、この配置は直りません。複合化は、配置そのものを組み替える数少ない機会です。

## 1-3　ヨーロッパの広場に学ぶ

ヨーロッパの都市では、中世から市庁舎・教会・市場が一つの広場を囲んできました。行政と祈りと商いが同じ場所に集まり、人の行き来そのものがまちの価値になっています。

- **シエナのカンポ広場（イタリア）**　市場や競技、行事の場として使われてきた広場です。市庁舎のプッブリコ宮が面しています。1349年に全体が舗装されました。
- **ドイツの町のマルクト広場**　「市場の広場」という名のとおり、市庁舎と教会が面し、定期市が開かれる町の中心です。
- **コペンハーゲンのストロイエ（デンマーク）**　現代になってから車を道路から外した例です。1962年に約1.1kmの通りを歩行者専用にしました。当時は多くの商店主が「客が減る」と反対しましたが、買い物客やカフェが増え、早くに成功しました。歩行者の空間は約1.58万㎡から約10万㎡に広がっています。

三つの例に共通するのは、**広場が「建物と建物のあいだの余り」ではなく、まちの主役として設計されている**ことです。施設の入口は広場に向き、人は広場を通って施設に入ります。広場に出ると、ほかの施設が目に入ります。

ストロイエの例は、もう一つ大事なことを教えています。車を外すことに、商店主は反対しました。客が車で来られなくなると考えたからです。結果は逆でした。**歩く人が増えると、商業の外部経済効果が回り始めます。** 日本の中心市街地で同じ議論をするとき、この経験は判断の材料になります。

## 1-4　日本での実践と国の制度

日本にも、広場で分断をつなぎ直した例があります。

- **富山市 グランドプラザ（2007年）**　再開発の区域内にあった路地のような市道をまとめ、両側の建物を後退させてつくった屋根付きの広場です。商業施設に隣り合い、路面電車の停留所で降りた人が、広場を通って商業施設や商店街へ向かう流れが生まれています。**道路を広場に変えて、分断をつなぎ直した例**です。
- **紫波町 オガール（岩手県）**　図書館などの公共施設と商業の建物が、中央の広場を囲んで配置されています（第5章・第12章）。

国も制度を整えました。2020年9月施行の都市再生特別措置法の改正で、「居心地が良く歩きたくなるまちなか」をつくる制度ができています。

| 制度 | 中身 | 複合化での使いどころ |
| --- | --- | --- |
| まちなかウォーカブル推進事業 | 街路を広場に変える整備などを支援する | 複合施設の前の道路を広場にする |
| 民間の敷地を広場として開放したときの固定資産税の軽減 | 民間が自分の敷地を公共の広場として使わせる場合の税の軽減 | 商業施設の前庭を、公共施設と共有の広場にする |
| 歩行者利便増進道路（ほこみち） | 道路を歩行者のために使い、公募で選ばれた者は最長20年の占用ができる | 広場に面した道路にカフェや売店を出す |

## 1-5　広場を中心に組む4つの原則

1. **複合化を建物の中だけで完結させない。**　建物の前に広場を置き、公共施設・文化施設・商業の入口を広場に向けます。建物の中を通路でつなぐだけでは、外から人は入ってきません。
2. **公共施設を散らさない。**　役所、図書館、ホールの建て替え先は、郊外の広い敷地ではなく、広場を囲む場所に選びます。建て替えの時期がずれていても、置く場所だけは先に決めておけます。
3. **道路と駐車場で分断しない。**　駐車場は外周にまとめ、広場のまわりは歩いて回れるようにします。必要なら道路の一部を広場に変えます。
4. **広場の運営者と予算を先に決める。**　マルシェやイベント、清掃を担う人（まちづくり会社や指定管理者）とその費用を、建物と同時に用意します。

4つめの原則は、いちばん見落とされます。広場は、建物と違って、完成した日から自然に使われるものではありません。**誰が、いつ、何のために広場を使うのかを決めていない広場は、ただの空き地になります。** 建物の工事費と同じ表に、広場の運営費を書いておきます。

## 1-6　規模に応じた3段の答え

広場をつくれるのは大きな都市だけではありません。規模に応じて、できることがあります。

| | 理想 | 次善 | 最低限 |
| --- | --- | --- | --- |
| 人口20万人以上 | 中心部の再編で、市庁舎・図書館・ホールと商業が広場を囲む配置にする。道路の一部を広場に変える | 再開発や建て替えの区域内に、屋根付きの広場を一つ設ける | 既存の公共施設の前庭を、イベントや出店に使えるよう規則を変える |
| 人口5万〜20万人 | 学校や庁舎の建て替えに合わせ、公共施設と商業を一つの敷地にまとめ、中央に広場を置く | 複合施設の入口側に広場を設け、駐車場を裏に回す | 庁舎や図書館の駐車場の一角を、週末だけ広場として使う |
| 人口5万人未満 | 支所・診療所・図書館・店を一か所にまとめた拠点の前に、小さな広場を置く | 道の駅や商業施設の前の空間を、公共の催しにも使えるよう協定を結ぶ | 公民館の前の空き地で、月1回の市（いち）を開く |

**「最低限」の欄は、予算がなくても今年度から始められること**です。広場の使い方を一度でも試すと、どこに人が来て、何が足りないかが分かります。大きな整備の前に、ここから始めます。

## 1-7　点検表

複合化の計画が「広場でつなぐ」考え方に沿っているかを、次の項目で確かめます。

- [ ] 複合施設の前に、誰でも入れる屋外の空間（広場）がある
- [ ] 公共施設と商業の入口が、広場に向いている
- [ ] 駐車場が、広場と施設のあいだに挟まっていない
- [ ] 広場から、ほかの施設や商店街へ歩いて行ける
- [ ] 広場を運営する人（組織）が決まっている
- [ ] 広場の運営費が、建物の事業費と同じ表に書かれている
- [ ] 広場を使う規則（出店、飲食、音、時間）が決まっている
- [ ] 建て替えの時期がずれる施設についても、将来置く場所が決まっている

### デベロッパーから見ると

**稼げるか。**　公共施設が平日の昼に人を呼ぶことは、商業施設にとって弱い時間帯を埋める効果があります。広場が施設の前にあれば、その人出が店の前を通ります。ただし、公共施設の来館者が実際にどれだけ買い回るかを示す公開データは、本書の執筆時点では見つけられていません【要確認】。事業計画では、この効果を上振れの要素として扱い、確実な収入としては見込まないのが安全です。

**どこにリスクがあるか。**　広場の運営費を誰が持つかが曖昧なまま始まると、清掃や警備の費用が商業側に寄ってきます。広場を共有するなら、運営者と費用の分担を協定に書きます。

**自治体に何を確かめるか。**　①広場の所有と管理の区分、②広場での出店やイベントの許可の手続、③駐車場の配置と台数の考え方（公共施設の利用者と商業の客で共用するか）、の3点です。
